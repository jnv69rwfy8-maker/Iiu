# مساحتي — Personal Utility Hub

نسخة محدثة من التطبيق الشخصي، جاهزة للنشر على GitHub Pages أو أي استضافة HTTPS تدعم Service Worker.

## الملفات
- `index.html` واجهة التطبيق وأدواته.
- `sw.js` عامل الخدمة والتخزين المؤقت وإظهار إشعارات المتصفح.
- `manifest.json` إعدادات تثبيت التطبيق على الهاتف.
- `apple-touch-icon.png` أيقونة التطبيق.

## التحديث على GitHub
1. فك ضغط الملف.
2. ارفع الملفات الأربعة إلى جذر المستودع، واستبدل النسخ القديمة.
3. انتظر تحديث GitHub Pages.
4. افتح رابط الموقع مرة من Safari أو Chrome مع اتصال الإنترنت.
5. إذا كان التطبيق مثبتًا على الشاشة الرئيسية، أغلقه وافتحه مرة أخرى بعد تحديث الصفحة.

## الإشعارات
- افتح الإعدادات داخل التطبيق ثم التنبيهات واضغط «تفعيل إشعارات المتصفح» واسمح بالإشعارات.
- تذكيرات تجديد الاشتراكات تعمل أثناء فتح التطبيق أو عند عودتك إليه.
- إشعارات الخلفية المجدولة بالكامل تحتاج إلى خادم Push وإعداد مفاتيح VAPID؛ هذا المشروع لا يحتوي على خادم Push، لذلك لا يدّعي إرسال تنبيهات مجدولة بعد إغلاق التطبيق.
- على iPhone، يلزم تثبيت الموقع كتطبيق من «إضافة إلى الشاشة الرئيسية» واستخدام إصدار iOS يدعم إشعارات تطبيقات الويب، مع السماح بالإشعارات من إعدادات النظام.

## الوقت والحكم والأماكن
- ويدجت الوقت والتاريخ يتحدث كل ثانية أثناء تشغيل التطبيق.
- تظهر حكمة مختلفة تلقائيًا حسب تاريخ اليوم، مع إمكانية اختيار حكمة أخرى يدويًا.
- دليل الأماكن يضم وجهات خروجات وأنشطة في القاهرة والجيزة. تحقق من المواعيد والأسعار والحجز مع المكان قبل الزيارة لأنها قابلة للتغيير.

## الخصوصية
بيانات التطبيق تحفظ محليًا على الجهاز باستخدام Local Storage وIndexedDB. لا توجد قاعدة بيانات سحابية.
